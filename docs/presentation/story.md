## Keys

These keys exist only while the deck is on screen. Leaving the route removes them. They are not the flight keys.

| Key | What it does |
|---|---|
| Right, Down, Page Down, Space | Next line, then the next slide |
| Left, Up, Page Up | Previous line, or the previous slide fully shown |
| Home / End | First slide / last slide |
| F | Full screen |
| N | Speaker notes |
| Escape | Close the slide list, then the notes, then full screen |
| Slide list | Opens direct links. A picked slide shows every line |

Direct hashes: `#title` `#problem` `#explore` `#fly` `#phone` `#learn` `#how` `#close` `#sources` `#orbit` `#excluded` `#evidence`.

Reduced motion shows the whole slide at once and does not rise the type. The deck never advances by itself.

Do not use M, L, T, E, V, I or 2 on this route. Space does not complete a checkpoint and does not award an orbit.

## Appendix — The orbit goal is a game setting

Periapsis means the lowest part of the path around Earth. Apoapsis means the highest part.

The helper’s classroom check is a bound path, periapsis at least 200 km, apoapsis at most 2,000 km, engines off for ten seconds. These cut-offs are ours. The public idea of an orbit is NASA’s. Do not blur those.

No successful input profile has been recorded. Do not sketch one from memory.
