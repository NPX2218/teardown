# 09 · Grok Imagine Implementation Plan

> **For agentic workers (Cursor Agent):** implement one task at a time, run the tests, stop for review. Steps use `- [ ]` checkboxes.

**Goal:** "Show this in action" turns the selected part (and, if the API allows, the current 3D view) into a Grok Imagine image, e.g. the booster landing on a droneship at night.
**Architecture:** The viewer exposes a snapshot of the canvas. `/api/imagine` builds a grounded prompt from the part's data and calls Grok Imagine. Results are cached so the demo never waits on a cold call.
**Tech Stack:** Grok Imagine API (per `docs/xai-notes.md`), Next.js route handler, vitest.
**Spec:** planning doc §2 feature 4.
**Owner:** A (Task 1) + B (Tasks 2–4). **Needs:** 03, 04. **First to cut** if behind.

## Global Constraints
See `00-index.md`. Image generation is slower than text: this plan uses `IMAGE_TIMEOUT_MS = 30000` instead of the 8 s text timeout.
