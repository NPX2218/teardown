# Sound credits

Only CC0 / Public Domain / NASA material is allowed here. `npx tsx scripts/check-sounds.ts` enforces it.

These nine files are original synthesis made for this exhibit with ffmpeg's audio generators (sine, noise, and envelopes). They are not recordings of a launch, a webcast, or a third-party library. Each file is dedicated to the public domain under the CC0 1.0 Universal deed. The source URL is that deed, not a download page for the audio.
