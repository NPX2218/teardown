# Audio credits

`manifest.json` is the Grok voice cache. It ships empty. Narration files added there are named by hash. They are not music.

`background.mp3` is separate. It is the laptop's background loop.

| File | Source | Licence | Note |
|---|---|---|---|
| background.mp3 | `scripts/make-background-music.sh` in this repo | CC0 1.0 — original sine-tone synthesis, no third-party recording | 60 s seamless pad, mono, 48 kbps. Not from YouTube or a sample library. |

To use a different track, replace `background.mp3` with a file you have the rights to, and update this table. Steps: [docs/background-music.md](../../docs/background-music.md).
